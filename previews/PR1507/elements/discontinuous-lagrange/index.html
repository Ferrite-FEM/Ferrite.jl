Discontinuous Lagrange

ELEMENT ATLAS Proof of concept

The same local nodal shapes, with independent dofs in each cell.

L² · cell-local values

The linear basis is identical to the continuous Lagrange basis on a single triangle. The difference is in assembly: dofs belong to the cell and are not shared. The sampling locations still lie at the vertices; a dof's location and its topological ownership are different concepts.

Definition

The reference cell is

\[\widehat K = \{(x,y):x,y\geq0,\ x+y\leq1\}.\]

The local approximation space is

\[\mathcal P_1 = \operatorname{span}\{1,x,y\}\]

The degrees of freedom are the linear functionals

\[\ell_i(u)=u(\boldsymbol x_i)\]

The basis is dual to these functionals:

\[\ell_i(\varphi_j)=\delta_{ij},\qquad I_h f=\sum_{i=1}^{n}\ell_i(f)\,\varphi_i.\]

A single-cell plot cannot show a discontinuity between cells. This example deliberately retains Ferrite's actual vertex sampling locations instead of moving them into the interior.

Use in Ferrite

using Ferriteip = DiscontinuousLagrange{RefTriangle, 1}()getnbasefunctions(ip)       # 3Ferrite.dof_functionals(ip) # functional kinds in local dof order

See dof functionals for the API, interpolations for supported variants, and Discontinuous Lagrange on DefElement for the wider family. Return to the element atlas.
