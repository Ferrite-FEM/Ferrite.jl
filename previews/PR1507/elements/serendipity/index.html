Serendipity

ELEMENT ATLAS Proof of concept

Quadratic edge traces with eight nodes and no centre dof.

H¹ · continuous values

Four vertex values and four edge-midpoint values determine this quadrilateral element. Its space omits the x²y² term of the nine-node tensor-product Q₂ element. The surface view makes the negative interior values of vertex basis functions visible.

Definition

The reference cell is

\[\widehat K = [-1,1]^2.\]

The local approximation space is

\[\mathcal S_2=\operatorname{span}\{1,x,y,x^2,xy,y^2,x^2y,xy^2\}\]

The degrees of freedom are the linear functionals

\[\ell_i(u)=u(\boldsymbol x_i)\]

The basis is dual to these functionals:

\[\ell_i(\varphi_j)=\delta_{ij},\qquad I_h f=\sum_{i=1}^{n}\ell_i(f)\,\varphi_i.\]

The reference square is [−1,1]². Ferrite also implements the quadratic serendipity hexahedron.

Use in Ferrite

using Ferriteip = Serendipity{RefQuadrilateral, 2}()getnbasefunctions(ip)       # 8Ferrite.dof_functionals(ip) # functional kinds in local dof order

See dof functionals for the API, interpolations for supported variants, and Serendipity on DefElement for the wider family. Return to the element atlas.
