**Goal:** support *every* interpolation Ferrite supports on the grid's reference shapes
(`RefQuadrilateral`/`RefHexahedron`) on a `NonConformingGrid` produced by `creategrid` —
any-order `Lagrange`, `Serendipity`, `DiscontinuousLagrange`, `Nedelec`, `RaviartThomas`,
their `VectorizedInterpolation`s, and interpolations added to Ferrite later — with the
hanging-interface constraints generated by one interpolation-agnostic mechanism, not
per-family special cases. Nothing in the builder may assume dofs sit on vertices, that an
entity carries at most one dof, or that weights are ½/¼: the interface dof set comes from
the interpolation's entity dof layout (`vertexdof_indices`/`edgedof_indices`/
`facetdof_indices`), and the weights come from a per-interpolation trace-interpolation
matrix with a generic implementation for nodal families (A.3.3). Consequently:

- `DiscontinuousLagrange` works trivially (empty interface dof set → no constraints);
- non-nodal families (`Nedelec`, `RaviartThomas`) need only their matrix implementation
  (A.4), never builder changes;
- concrete milestones below (Q2, Q3, Nédélec/RT order 1) are *validation instances*, not
  the scope — the scope is the mechanism.

The grid stays Q1 geometry throughout (geometry order is Plan B and fully decoupled).

**Architecture** (the deal.II split): the forest/`creategrid` side emits only geometry
(Q1 nodes/cells) plus *combinatorial* conformity topology — no dof knowledge, no weights.
The `DofHandler` distributes dofs unchanged. A generic constraint builder (the
`make_hanging_node_constraints` analogue) owns all algebra, combining the topological
records with per-interpolation "subentity interpolation matrices" (the
`get_subface_interpolation_matrix` analogue).

```
ForestBWG ──creategrid──▶ NonConformingGrid
                            ├─ cells/nodes (Q1 geometry, unchanged)
                            └─ conformity_info::ConformityInfo   ← NEW: topological only
                                 ├─ hanging_facets :: Vector{HangingFacet}
                                 └─ hanging_edges  :: Vector{HangingEdge}   (3D)

DofHandler(grid)  — distributes dofs per interpolation (machinery unchanged)

add!(ch, ConformityConstraint(:u))
  └─ per record: subentity_interpolation_matrix(ip, …) → AffineConstraints
```

Reference points: p4est emits topology only (`face_code` + `p4est_lnodes_decode`; the
algebra is the application's job); deal.II combines topological hanging-face detection
with the element's interface constraint matrices (`FiniteElement::constraints()`,
`get_subface_interpolation_matrix`). Ferrite already has the deal.II-side prerequisites:
entity-wise dof distribution, orientation-aware `permute_and_push!`, Nédélec/RT
interpolations.

## A.1 Topological conformity contract (`src/Adaptivity/ncgrid.jl`)

Replace the node-level `Dict{Int, Vector{Int}}` with:

```julia
struct HangingFacet
    coarse::FacetIndex          # (cell, local facet), Ferrite numbering
    fine::Vector{FacetIndex}    # the 2 (2D) / 4 (3D) covering sub-facets, unordered
end

struct HangingEdge              # 3D only (edge-only hangs exist without a hanging face)
    coarse::EdgeIndex
    fine::NTuple{2, EdgeIndex}  # one representative (cell, ledge) per half-edge
end

struct ConformityInfo
    hanging_facets::Vector{HangingFacet}
    hanging_edges::Vector{HangingEdge}
end
```

Design decisions:

- **`FacetIndex`/`EdgeIndex` (cell + local id), not node tuples.** With a cell context the
  builder fetches dofs via `celldofs(dh, cell)[facetdof_indices(ip)[lfacet]]` — no
  `EntityMaps` needed — and the dof order is `permute_and_push!`-consistent (cell-local
  order corresponds to the cell-local entity parametrization).
- **`fine` is unordered; child position and relative orientation are derived, not
  stored.** Each fine facet shares exactly one corner node id with the coarse facet — that
  pins its quadrant/half; the order of the remaining corner ids pins rotation/reflection.
  Node identity is canonical, so this is deterministic, and p4est's z-order conventions
  never leak into the public contract.
- `NonConformingGrid` needs no struct change (`conformity_info::CIT` is already a free
  type parameter).

## A.2 Emission in `creategrid` (`src/Adaptivity/BWG.jl`)

Hanging-vertex *creation* is untouched (the Q1 mesh needs those nodes); only the
recording changes.

1. **Intra-tree facets** — `_visit_face!`: `ls` (the `LeafSupport`) already holds the
   coarse leaf (index `ci` from `_mixed_support`) and the fine face-children with element
   indices; today only node ids are kept. Coarse local facet: normal axis = the axis not
   set in `c.axes`, side from comparing `c.anchor` with the coarse octant's anchor, BWG
   face index → Ferrite facet via `𝒱₂_perm`/`𝒱₃_perm` (same tables as
   `reconstruct_facetsets`). Fine facets: the opposite BWG face, same permutation. Emit
   one `HangingFacet`.
2. **Intra-tree edges (3D)** — `_visit_edge3d!`: fires exactly once per hanging edge even
   when it borders several hanging faces (existing uniqueness guarantee) → emit one
   `HangingEdge`. Local edge ids from the edge axis + transverse position via the
   existing `edge_perm` tables. Several fine leaves may share a half-edge; pick one
   representative (lowest element id) — any representative identifies the same dofs.
3. **Inter-tree** — `_emit_interface_face!`: emit the same records from the interface
   descent. Plumbing: `_iter_interface!` currently passes only `offR`; thread `offL`
   through so the coarse element id (`offL + loL` in the `lL && !lR` branch) is
   available. Also emit the face's four sub-edge `HangingEdge`s here, **deduplicated** on
   the coarse edge's node pair (a `Set` during construction). Relative orientation across
   the tree interface needs no special handling in the record — it falls out of the
   node-id derivation in the builder.
4. **Retire `cons2`/`cons4`** and the `hnodes` dict in `creategrid` once the parity gate
   (A.3) passes. The Q1 weights previously hardcoded are then *derived* by the generic
   builder.
5. **Enforce 2:1 strictly**: `_subtree_corner_ref`'s tolerant `>1`-level-jump descent
   becomes a hard error — partially constrained interfaces cannot yield a conforming
   space for any order. (`creategrid` already documents the balance requirement.)

## A.3 Generic constraint builder (`src/Adaptivity/constraints.jl`)

1. **Driver.** `add!(ch, ::ConformityConstraint)` drops the single-field assert, loops
   subdofhandlers × fields, iterates `hanging_facets` then `hanging_edges`. A
   `constrained::BitSet` dedups dofs reachable from several records (a fine vertex dof on
   a 3D hanging edge is reachable from up to two facet records and one edge record; the
   constraints are identical — keep the first, `@debug`-assert equality).
2. **Kernel (per record, per field).**
   1. Coarse trace dofs: `celldofs(dh, coarse.cell)[facetdof_indices(ip)[lfacet]]` —
      vertex + edge-interior + face-interior dofs of the facet, in cell-local order.
   2. Fine trace dofs: same per fine facet.
   3. Child embedding + orientation from node ids (shared corner → quadrant; remaining
      corner order → one of 2 configs in 2D, 4 quadrants × 8 symmetries in 3D). Express
      the orientation with the *existing* BWG machinery — `rotation_permutation`
      (Table 3 [BWG2011]) and the `compute_face_orientation`/`compute_edge_orientation`
      conventions — rather than inventing a second symmetry encoding; the builder only
      adds the node-id-based detection on the materialized grid.
   4. Interpolation matrix `C` (fine trace = `C` × coarse trace) from A.3.3.
   5. Emit: skip identity rows (a fine corner coinciding with a coarse corner is already
      the *same global dof* — the mesh shares that node); every other fine dof gets
      `AffineConstraint(fine_dof, coarse_dofs .=> C[row, :], 0.0)`, filtered through the
      dedup set.

   The edge kernel is the 1D restriction (`edgedof_indices`). Facet records alone are
   complete for their boundary sub-edge dofs: coarse trace functions vanishing on a
   boundary edge contribute zero weight, so those dofs automatically couple only to the
   coarse *edge* dofs. Edge records cover the edge-only hanging case.
3. **New interpolation-level API** — the `get_subface_interpolation_matrix` analogue:

   ```julia
   subentity_interpolation_matrix(ip::Interpolation, ::Val{entdim}, child, orient)
   ```

   Generic fallback for nodal interpolations (any-order Lagrange, Serendipity): take the
   fine dofs' `reference_coordinates` restricted to the facet, map through the child
   embedding into the coarse facet's parametrization, evaluate the coarse trace shape
   functions there. Pure reference-element computation; memoize per
   `(ip, entdim, child, orient)` — the config set is small and finite.
   `VectorizedInterpolation`: apply the scalar matrix per component with the component
   stride (generalizes the current `+ vd - 1` loop).
4. **Guard (documented upstream limitation):** interpolations with more than one
   face-interior dof in 3D (Lagrange order ≥ 3 on hexes, higher RT) error out clearly —
   blocked on `SurfaceOrientationInfo` being a stub in `DofHandler.jl`
   (`# TODO fill struct`), which affects conforming grids too. Q2 (one symmetric face
   dof) is unaffected.
5. **`EntityMaps` retirement.** The builder no longer needs `dh.entitymaps`; the
   retention special-case for `NonConformingGrid` in `DofHandler.jl` becomes dead. List
   the orphans and confirm before deleting (user preference).

## A.4 Non-nodal elements (Nédélec, RT — lowest order first)

- Topology and dof lookup come free from A.1–A.3: these elements have only edge/face
  dofs, so the interface dof set is exactly what `edgedof_indices`/`facetdof_indices`
  deliver, and tangential/normal-only continuity is automatic (no vertex dofs exist to
  over-constrain).
- Implement `subentity_interpolation_matrix` analytically for `Nedelec{*, 1}` and
  `RaviartThomas{*, 1}`: the fine half-edge tangential moment is ½ the coarse edge
  moment, sign from the relative edge direction — deterministic under Ferrite's
  ascending-vertex-id dof convention (the structural fix for deal.II's historic
  `FE_Nedelec` hanging-sign bugs that motivated `FE_NedelecSZ`).
- Higher-order Nédélec/RT: deferred. The general mechanism is a dof-functional API
  (evaluate the fine element's moment functionals against the coarse trace by
  quadrature); design `subentity_interpolation_matrix` so this slots in behind the same
  signature without touching the builder.

## Tests

- **Parity**: Q1 golden values through the generic path (M1 gate).
- **Patch tests (the acid test)**: a global polynomial of the field's order reproduced
  *exactly* — Q2/Q3, 2D/3D, intra-tree, inter-tree, 3D face-hang, 3D edge-only-hang,
  corner-heavy configurations.
- **Rotated macro elements (mandatory in every tier)**: tree coordinate axes cannot be
  assumed aligned, so the inter-tree cases must run on multi-tree meshes whose macro
  elements are rotated against each other, sweeping *all* relative orientations the BWG
  encoding admits — in 2D both edge orientations, in 3D every face rotation of Table 3
  [BWG2011] plus edge- and corner-only tree connections. Build the sweep by permuting
  the coarse-mesh cell connectivity (the topologically rotated two-tree fixtures already
  in `test/test_p4est.jl` are the seed) and **reuse the existing orientation machinery**
  — `rotation_permutation`, `compute_face_orientation`/`compute_edge_orientation`,
  `transform_facet`/`transform_edge`/`transform_corner` — to construct and cross-check
  the expected configurations instead of writing a parallel encoding in the tests. This
  directly validates the builder's orientation derivation (A.3.2.3), the part of the
  design most exposed to non-aligned axes.
- **Nédélec/RT**: constant-field tangential/normal continuity across hanging interfaces,
  over the same full rotation sweep (sign errors only surface on non-aligned
  connections).
- **Interactions**: hanging dof ∩ Dirichlet facetset (ConstraintHandler conflict
  resolution), multi-field with different orders, vectorized fields.
- **Convergence**: Q2 on the adaptive L-shape (tutorial) recovers the optimal rate.

## Risks

- **3D orientation derivation** (quadrant × 8 symmetries) — mitigate with the exhaustive
  rotated-macro-element sweep (see Tests): every configuration through mutually rotated
  two-tree forests, cross-checked against `rotation_permutation`/
  `compute_face_orientation`.
- **Nédélec signs** — mitigated by the vertex-id convention, but the orientation-sweeping
  patch test must pass before anything is trusted.
- **Face-interior dof permutation** — upstream DofHandler gap (`SurfaceOrientationInfo`);
  scoped out with a guard rather than fixed here.

## Relation to Plan B (quadratic geometry)

Fully decoupled in usage and implementation; the shared seam is the `ConformityInfo`
contract, which Plan B does not touch. Both plans edit the visitor callbacks in `BWG.jl`
— whichever lands second rebases over the other.
